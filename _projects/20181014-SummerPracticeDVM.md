## Summer Practice at DVM Technologies Inc.

2018-10-14

* * *

TODO

In this summer practice, I have accomplished using a cloud-based Internet of Things platform via its web interface, a visual REST client, and node.js scripts that are written by myself. I have created alarms in this platform that takes actions without any human interaction, which indeed fulfills the aim of the Internet of Things. I have communicated with a PIC via UART, using a computer software. I have achieved developing a \\textit{Hello World} and \\textit{LED blinking} project and implementing a source code between different development kits, which are targeted for an ARM Cortex-M3 processor, by understanding the basics of embedded systems and embedded programming. I have succeeded in sending commands and receiving data from metering devices, using an M-Bus medium. On the whole, I have learned the fundamentals of an IoT system.
