# Karplus-Strong String Synthesis

2019-11-23

Undergraduate research, Oct 2019 - Jul 2020

[METU Spatial Audio Research Group (METU SPARG)](http://sparg.ii.metu.edu.tr/)

_Advisor: [Huseyin Hacihabiboglu, Ph.D., SMIEEE](http://www.hacihabiboglu.org/)_.

* * *

Topic: Guitar modeling and simulation using Extended Karplus-Strong algorithm.

1. Understanding the theory of Karplus-strong algorithm in physical modeling sense, physical waveguides.
2. Move onto Extended Karplus-Strong algorithm theory, understanding the extended effects.
3. Transforming this approach in digital domain, and implementing into a program (using JUCE or STK library)
4. Parameter estimation using recorded audio of playing a string of a guitar.
5. Playing music scores using the synthesised voice of a real guitar
